# LCK Fan Pickems

Web app for LCK (League of Legends Champions League) fan pickems. Built with Astro <3

## Preview

[Watch the demo video](https://github.com/user-attachments/assets/ef2fd1a2-2628-4404-a7b2-d69cccadc545)

## Development Process

This project was developed using a combination of tools to streamline the development process.

### Initial Scaffolding

**Kiro** was used for the initial project specifications and for generating the boilerplate code. This allowed for a rapid setup and a solid foundation to build upon.

### Polishing and Refinement

**Antigravity** was instrumental in polishing the final product. It was used for improving the user experience (UX), fixing bugs, and ensuring the overall quality of the application.

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/LautaroLobo12/fanpickems.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```

### Running the application

```sh
npm run dev
```
