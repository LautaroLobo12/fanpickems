# Team Logos

This directory should contain team logo images for the LCK teams.

## Required Logo Files

- t1.png - T1 logo
- geng.png - Gen.G logo  
- hle.png - Hanwha Life Esports logo
- kt.png - KT Rolster logo
- dk.png - DWG KIA logo
- kdf.png - Kwangdong Freecs logo
- drx.png - DRX logo
- brion.png - OK BRION logo
- ns.png - Nongshim RedForce logo
- fearx.png - FearX logo

## Image Requirements

- Format: PNG (recommended) or JPG
- Size: 64x64px or 128x128px (square aspect ratio)
- Background: Transparent (for PNG) or team colors

## Placeholder

For development, you can use placeholder images or the team names will be displayed if logos are not available.
